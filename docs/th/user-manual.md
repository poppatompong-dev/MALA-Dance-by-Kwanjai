# คู่มือพนักงานหน้าร้าน

คู่มือนี้สำหรับแคชเชียร์และพนักงานขายของร้านหม่าล่าแดนซ์ by ขวัญใจ ใช้สำหรับขายสินค้า รับเงิน เพิ่มลูกค้าหน้าร้าน ใช้รางวัลสะสมแต้ม และพิมพ์ใบเสร็จ

## 1. เข้าสู่ระบบ

1. เปิด URL ที่ร้านให้ (เช่น `https://mala-dance-by-kwanjai.vercel.app/login` หรือ `http://127.0.0.1:8000/login` สำหรับ local)
2. ใส่อีเมลและรหัสผ่านที่ผู้ดูแลระบบให้
3. กด `เข้าสู่ระบบ`
4. เข้าเมนู `ขายหน้าร้าน`

บัญชีเดโมสำหรับฝึก:

- อีเมล: `demo@qtecsolution.net`
- รหัสผ่าน: `87654321`

## 2. ขายหน้าร้าน

1. เลือกลูกค้า หากเป็นลูกค้าทั่วไปให้ใช้ `ลูกค้าหน้าร้าน` หากเป็นลูกค้าประจำให้เลือกชื่อเพื่อสะสมแต้ม
2. เลือกประเภทออเดอร์: `ทานที่ร้าน (dine_in)`, `กลับบ้าน (takeaway)`, `เดลิเวอรี (delivery)`
3. ค้นหาสินค้าด้วยชื่อหรือ SKU (สแกนบาร์โค้ดก็ได้)
4. กดสินค้าที่ต้องการเพื่อเพิ่มเข้าตะกร้า
5. ปรับจำนวน ระบุระดับความเผ็ด (`spice_level`) และ toppings ถ้ามี
6. หากลูกค้ามีสิทธิรางวัล (โปรโมชั่น คูปอง วันเกิด แลกแต้ม) จะแสดงให้เลือกใช้
7. ใส่ส่วนลดเพิ่มเติม (ถ้ามีและได้รับอนุญาต)
8. ตรวจยอดก่อนส่วนลด ส่วนลดทุกประเภท ยอดสุทธิ และยอดรับเงิน
9. ใส่ยอดเงินที่ลูกค้าชำระ
10. กด `ชำระเงิน`
11. ยืนยันรายการและพิมพ์ใบเสร็จ POS

## 3. ตัวอย่างการขาย

ลูกค้าสั่ง:

- หมูสามชั้นหม่าล่า 5 ไม้ (เผ็ดกลาง)
- ไส้กรอกชีส 2 ไม้
- ชามะนาว 1 แก้ว

วิธีทำ:

1. เลือก `ลูกค้าหน้าร้าน`
2. เลือก `ทานที่ร้าน`
3. ค้นหา `หมูสามชั้น` แล้วเพิ่ม 5 ไม้ ระบุ spice_level `medium`
4. ค้นหา `ไส้กรอกชีส` แล้วเพิ่ม 2 ไม้
5. ค้นหา `ชามะนาว` แล้วเพิ่ม 1 แก้ว
6. ตรวจยอดรวม
7. รับเงินและกด `ชำระเงิน`
8. พิมพ์ใบเสร็จ POS

## 4. การใช้ส่วนลดและรางวัล

มี 2 ทาง:

- **ส่วนลดด้วยมือ**: ใส่จำนวนเงินบาทในช่อง `ส่วนลด` เช่น ลด 10 บาท ใส่ `10` ใช้เมื่อเจ้าของร้าน/ผู้จัดการอนุญาต
- **รางวัล/โปรโมชั่น**: ระบบจะแสดงรายการที่ลูกค้าใช้ได้ในกล่อง `Available Rewards` คลิกเพื่อเลือกใช้ ระบบจะคำนวณส่วนลดและแต้มอัตโนมัติ

แต้มสะสม:

- ทุกการซื้อ 10 บาท ลูกค้าได้ 1 แต้ม
- ใช้แต้มแลกส่วนลดได้ตามกฎที่ Admin ตั้งไว้

## 5. เพิ่มลูกค้าระหว่างขาย

ใช้เมื่อลูกค้าประจำต้องการให้ร้านเก็บประวัติ ยอดค้างชำระ หรือสะสมแต้ม

1. เปิดช่องเลือกลูกค้า
2. พิมพ์ชื่อลูกค้าใหม่
3. กดเพิ่มลูกค้า (ใส่เบอร์โทรและวันเกิดด้วยถ้าได้ เพื่อให้ใช้สิทธิ์วันเกิดได้)
4. เลือกลูกค้าที่เพิ่มใหม่ก่อนชำระเงิน

## 6. กรณีต้องยกเลิกบิล (Void)

หากบิลผิดและต้องการยกเลิกหลังชำระแล้ว:

1. เข้าเมนู `การขาย > รายการขาย`
2. ค้นหาบิลที่ต้องการยกเลิก
3. กด `ยกเลิก (Void)` และยืนยัน
4. ระบบจะคืนสต็อก คืนแต้มที่ลูกค้าได้ และบันทึก audit log

**สำคัญ**: เฉพาะผู้มีสิทธิ์เท่านั้นที่ทำได้ พนักงานทั่วไปต้องแจ้งผู้จัดการ

## 7. การแก้ปัญหาหน้างาน

| ปัญหา | วิธีแก้ |
|---|---|
| หาสินค้าไม่เจอ | ลองค้นด้วยคำสั้น เช่น `หมู`, `ชา`, `น้ำ` หรือสแกนบาร์โค้ด |
| สินค้ากดขายไม่ได้ | สต็อก = 0 หรือถูกปิดขาย แจ้งผู้ดูแลระบบ |
| จำนวนผิด | ปรับจำนวนในตะกร้าก่อนชำระเงิน |
| ยอดเงินผิด | ตรวจส่วนลด รางวัล และยอดรับเงินก่อนกดชำระ |
| รางวัลไม่ขึ้น | ตรวจว่าลูกค้าตรงเงื่อนไข (แต้มพอ, ในช่วงเวลาที่กำหนด, ยอดถึงขั้นต่ำ) |
| พิมพ์ใบเสร็จไม่ออก | จดเลขที่บิลไว้ แล้วแจ้งผู้ดูแลระบบตรวจเครื่องพิมพ์ |
| ทำบิลผิดหลังชำระแล้ว | แจ้งผู้จัดการ ขอ Void บิล |

## 8. ข้อควรระวัง

- ใช้บัญชีของตัวเองเท่านั้น (มีบันทึก audit log ทุกการกระทำ)
- ตรวจรายการก่อนกดชำระเงินทุกครั้ง
- ห้ามล้างตะกร้าหลังรับเงินจากลูกค้าแล้ว
- หากระบบช้า ให้หยุดกดซ้ำและแจ้งผู้ดูแลระบบ
- ปิดกะแล้วควรแจ้งยอดเงินสดหรือยอดโอนจริงให้ผู้จัดการตรวจ
- ห้ามแก้ข้อมูลลูกค้า/สินค้า/แต้มเองหากไม่มีสิทธิ์
