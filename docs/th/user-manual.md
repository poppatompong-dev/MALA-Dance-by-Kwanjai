# คู่มือพนักงานหน้าร้าน

คู่มือนี้สำหรับแคชเชียร์และพนักงานขายของร้านหม่าล่าแดนซ์ by ขวัญใจ ใช้สำหรับขายสินค้า รับเงิน เพิ่มลูกค้าหน้าร้าน และพิมพ์ใบเสร็จ

## 1. เข้าสู่ระบบ

1. เปิดเว็บ `https://mala-dance-by-kwanjai.vercel.app/login`
2. ใส่ชื่อผู้ใช้และรหัสผ่านที่ผู้ดูแลระบบให้
3. กด `เข้าสู่ระบบ`
4. เข้าเมนู `ขายหน้าร้าน`

## 2. ขายหน้าร้าน

1. เลือกประเภทออเดอร์: `ทานที่ร้าน`, `กลับบ้าน`, `เดลิเวอรี`
2. เลือกลูกค้า หากเป็นลูกค้าทั่วไปให้ใช้ `ลูกค้าหน้าร้าน`
3. ค้นหาสินค้าด้วยชื่อหรือ SKU (สแกนบาร์โค้ดก็ได้)
4. กดสินค้าที่ต้องการเพื่อเพิ่มเข้าตะกร้า (ระบุระดับความเผ็ดในป๊อปอัพ)
5. ปรับจำนวนในตะกร้า
6. ใส่ส่วนลด (ถ้ามีและได้รับอนุญาต) — เป็นจำนวนบาท
7. ตรวจยอดก่อนส่วนลด ส่วนลด ยอดสุทธิ และยอดรับเงิน
8. ใส่ยอดเงินที่ลูกค้าชำระ
9. กด `ชำระเงิน`
10. ยืนยันรายการและพิมพ์ใบเสร็จ POS

## 3. ตัวอย่างการขาย

ลูกค้าสั่ง:

- หมูสามชั้นหม่าล่า 5 ไม้ (เผ็ดกลาง)
- ไส้กรอกชีส 2 ไม้
- ชามะนาว 1 แก้ว

วิธีทำ:

1. เลือก `ทานที่ร้าน`
2. เลือก `ลูกค้าหน้าร้าน`
3. ค้นหา `หมูสามชั้น` เลือก `เผ็ดกลาง` แล้วปรับเป็น 5 ไม้
4. ค้นหา `ไส้กรอกชีส` แล้วเพิ่ม 2 ไม้
5. ค้นหา `ชามะนาว` แล้วเพิ่ม 1 แก้ว
6. ตรวจยอดรวม
7. รับเงินและกด `ชำระเงิน`
8. พิมพ์ใบเสร็จ POS

## 4. การใช้ส่วนลด

ใส่ส่วนลดเป็นจำนวนเงินบาทในช่อง `ส่วนลด` เช่น ลด 10 บาท ใส่ `10` ก่อนกดชำระเงิน

ใช้ส่วนลดเมื่อเจ้าของร้านหรือผู้จัดการอนุญาตเท่านั้น และควรตรวจยอดสุทธิทุกครั้งหลังใส่ส่วนลด

## 5. เพิ่มลูกค้าระหว่างขาย

ใช้เมื่อลูกค้าประจำต้องการให้ร้านเก็บประวัติหรือยอดค้างชำระ

1. เปิดช่องเลือกลูกค้า
2. พิมพ์ชื่อลูกค้าใหม่
3. กดเพิ่มลูกค้า (ใส่เบอร์โทรด้วยถ้าได้)
4. เลือกลูกค้าที่เพิ่มใหม่ก่อนชำระเงิน

## 6. กรณีต้องยกเลิกบิล (Void)

หากบิลผิดและต้องการยกเลิกหลังชำระแล้ว:

1. เข้าเมนู `การขาย > รายการขาย`
2. ค้นหาบิลที่ต้องการยกเลิก
3. กด `ยกเลิก (Void)` และยืนยัน
4. ระบบจะคืนสต็อกและบันทึก audit log

**สำคัญ**: เฉพาะผู้มีสิทธิ์เท่านั้นที่ทำได้ พนักงานทั่วไปต้องแจ้งผู้จัดการ

## 7. การแก้ปัญหาหน้างาน

| ปัญหา | วิธีแก้ |
|---|---|
| หาสินค้าไม่เจอ | ลองค้นด้วยคำสั้น เช่น `หมู`, `ชา`, `น้ำ` หรือสแกนบาร์โค้ด |
| สินค้ากดขายไม่ได้ | สต็อก = 0 หรือถูกปิดขาย แจ้งผู้ดูแลระบบ |
| จำนวนผิด | ปรับจำนวนในตะกร้าก่อนชำระเงิน |
| ยอดเงินผิด | ตรวจส่วนลดและยอดรับเงินก่อนกดชำระ |
| พิมพ์ใบเสร็จไม่ออก | จดเลขที่บิลไว้ แล้วแจ้งผู้ดูแลระบบตรวจเครื่องพิมพ์ |
| ทำบิลผิดหลังชำระแล้ว | แจ้งผู้จัดการ ขอ Void บิล |

## 8. ข้อควรระวัง

- ใช้บัญชีของตัวเองเท่านั้น (มีบันทึก audit log ทุกการกระทำ)
- ตรวจรายการก่อนกดชำระเงินทุกครั้ง
- ห้ามล้างตะกร้าหลังรับเงินจากลูกค้าแล้ว
- หากระบบช้า ให้หยุดกดซ้ำและแจ้งผู้ดูแลระบบ
- ปิดกะแล้วควรแจ้งยอดเงินสดหรือยอดโอนจริงให้ผู้จัดการตรวจ
- ห้ามแก้ข้อมูลลูกค้า/สินค้าเองหากไม่มีสิทธิ์
