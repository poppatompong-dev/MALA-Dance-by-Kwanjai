# คู่มือผู้ใช้งาน QPOS ร้านหม่าล่า

## สำหรับใคร

คู่มือนี้สำหรับแคชเชียร์และพนักงานหน้าร้านที่ต้องขายสินค้า รับเงิน ดูยอดค้างชำระ และพิมพ์ใบเสร็จ ไม่จำเป็นต้องรู้เรื่องเทคนิคหรือการตั้งค่าระบบหลังบ้าน

## 1. เข้าสู่ระบบ

1. เปิดเว็บ `http://127.0.0.1:8000/login`
2. ใส่อีเมลและรหัสผ่านที่แอดมินให้
3. กด `เข้าสู่ระบบ`
4. ถ้าเข้าสำเร็จ ให้ไปที่เมนู `ขายหน้าร้าน`

บัญชีทดลองสำหรับฝึกใช้งาน:

- อีเมล: `demo@qtecsolution.net`
- รหัสผ่าน: `87654321`

ถ้าเข้าระบบไม่ได้ ให้ตรวจว่าพิมพ์อีเมลถูกต้อง ไม่มีเว้นวรรค และเปิด URL ถูกเครื่อง

## 2. ภาพรวมหน้าขายหน้าร้าน

หน้า POS ใช้สำหรับทำบิลขาย โดยทั่วไปจะแบ่งงานเป็น 4 ส่วน:

1. ช่องค้นหาสินค้า ใช้พิมพ์ชื่อสินค้า หรือสแกนบาร์โค้ดถ้ามี
2. รายการสินค้า ใช้กดเพิ่มสินค้าเข้าบิล
3. รายการในบิล ใช้ตรวจสินค้า จำนวน ราคา และยอดรวม
4. ช่องรับเงิน ใช้ใส่ส่วนลด ยอดรับเงิน และกดชำระเงิน

ก่อนกดชำระเงิน ให้ตรวจชื่อสินค้า จำนวน และยอดรวมทุกครั้ง

## 3. ขายหน้าร้าน

1. ไปที่เมนู `ขายหน้าร้าน`
2. เลือกลูกค้า ถ้าเป็นลูกค้าทั่วไปให้ใช้ `ลูกค้าหน้าร้าน`
3. ค้นหาสินค้าด้วยชื่อสินค้า เช่น `หมูสามชั้น`, `ลูกชิ้น`, `ชามะนาว`
4. กดสินค้าเพื่อเพิ่มเข้าบิล
5. ถ้าลูกค้าซื้อหลายชิ้น ให้กดเพิ่มจำนวนในบิล หรือกดสินค้าซ้ำ
6. ตรวจจำนวนและยอดรวมในตะกร้า
7. ใส่ส่วนลดถ้ามี
8. ใส่ยอดที่ลูกค้าชำระ
9. ตรวจยอดค้างชำระหรือเงินทอน
10. กด `ชำระเงิน`
11. ยืนยันรายการ
12. พิมพ์ใบเสร็จหรือจดเลขที่บิลไว้

## 4. ค้นหาสินค้าให้เร็ว

ใช้คำสั้น ๆ ที่พนักงานจำได้ง่าย เช่น:

- `หมู` เพื่อหาเมนูหมู
- `ไก่` เพื่อหาไก่หมักหรือไก่เสียบไม้
- `ชีส` เพื่อหาไส้กรอกชีส
- `ชา` เพื่อหาเครื่องดื่มชา
- `น้ำ` เพื่อหาเครื่องดื่มขวดหรือเมนูน้ำ

ถ้าร้านมีบาร์โค้ด ให้คลิกช่องบาร์โค้ดแล้วสแกนสินค้า ระบบจะเพิ่มสินค้าเข้าบิลตามข้อมูลที่ตั้งไว้

## 5. เพิ่มลูกค้าระหว่างขาย

ถ้าลูกค้าประจำต้องการให้เก็บชื่อหรือเบอร์โทร:

1. ในหน้า POS กดเลือกหรือเพิ่มลูกค้า
2. ใส่ชื่อลูกค้า เช่น `คุณเมย์`
3. ใส่เบอร์โทรถ้ามี
4. บันทึก
5. เลือกลูกค้าคนนั้นก่อนชำระเงิน

สำหรับลูกค้าทั่วไปที่ไม่ต้องเก็บข้อมูล ให้ใช้ `ลูกค้าหน้าร้าน` เพื่อลดเวลาทำบิล

## 6. ส่วนลด รับเงิน และยอดค้างชำระ

ส่วนลดใช้เมื่อต้องลดราคาหน้าร้าน เช่น โปรโมชันซื้อครบ 100 บาท ลด 10 บาท ให้ใส่ยอดส่วนลดก่อนรับเงิน

ช่อง `รับเงิน` คือจำนวนเงินที่ลูกค้าจ่ายจริง:

- ถ้าลูกค้าจ่ายครบ ระบบควรแสดงยอดค้างชำระเป็น 0 หรือแสดงเงินทอนตามที่รับเกิน
- ถ้าลูกค้าจ่ายไม่ครบ ระบบจะแสดงยอดค้างชำระ ให้ใช้เฉพาะกรณีร้านอนุญาตให้ติดเงิน
- ถ้าพิมพ์ยอดผิด ให้แก้ตัวเลขก่อนกดชำระเงิน

ตัวอย่าง: ยอดสุทธิ 85 บาท ลูกค้าจ่าย 100 บาท ให้ใส่ `100` ในช่องรับเงิน แล้วตรวจว่าเงินทอนเป็น 15 บาท

## 7. ใบเสร็จ

หลังชำระเงิน ระบบจะแสดงใบเสร็จ ให้ตรวจ:

1. ชื่อร้านและเบอร์โทร
2. เลขที่บิล
3. วันที่ขาย
4. รายการสินค้า
5. ยอดรวม ส่วนลด ยอดสุทธิ และยอดรับเงิน
6. ชื่อลูกค้าถ้ามี

ถ้าเครื่องพิมพ์พร้อม ให้กด `พิมพ์ใบเสร็จ` ถ้าพิมพ์ไม่ออก ให้จดเลขที่บิลไว้ก่อนและแจ้งแอดมินตรวจเครื่องพิมพ์

## 8. ตัวอย่างการขาย

ลูกค้าซื้อ:

- หมูสามชั้นหม่าล่า 5 ไม้
- ไส้กรอกชีส 2 ไม้
- ชามะนาว 1 แก้ว

วิธีทำ:

1. เลือก `ลูกค้าหน้าร้าน`
2. ค้นหา `หมูสามชั้น` แล้วเพิ่ม 5 ไม้
3. ค้นหา `ไส้กรอกชีส` แล้วเพิ่ม 2 ไม้
4. ค้นหา `ชามะนาว` แล้วเพิ่ม 1 แก้ว
5. ตรวจยอดรวม
6. รับเงินและกดชำระเงิน
7. ตรวจใบเสร็จ

## 9. การแก้ปัญหาหน้างาน

| ปัญหา | วิธีแก้ |
|---|---|
| เข้าระบบไม่ได้ | ตรวจอีเมล รหัสผ่าน และ URL ถ้ายังไม่ได้ให้แจ้งแอดมิน |
| หาสินค้าไม่เจอ | ลองค้นหาด้วยคำสั้นลง เช่น `หมู` หรือแจ้งแอดมินให้เพิ่มสินค้า |
| สินค้าขึ้นแต่กดขายไม่ได้ | แจ้งแอดมินตรวจสต็อกหรือสถานะสินค้า |
| จำนวนในบิลผิด | ปรับจำนวนในบิลก่อนกดชำระเงิน |
| ยอดเงินผิด | ตรวจส่วนลดและยอดรับเงิน ถ้ายังไม่ชำระให้ล้างบิลแล้วทำใหม่ |
| กดชำระเงินไม่ได้ | ตรวจว่าเลือกผู้ซื้อและมีสินค้าในบิลแล้ว |
| ลูกค้าจ่ายไม่ครบ | ถ้าร้านไม่ให้ติดเงิน ให้แก้ยอดรับเงินเป็นยอดเต็มก่อนชำระ |
| ใบเสร็จไม่พิมพ์ | ตรวจเครื่องพิมพ์ กระดาษ และลองกดพิมพ์ซ้ำ |
| ทำบิลผิดหลังชำระแล้ว | จดเลขที่บิลและแจ้งแอดมิน ไม่ควรแก้เองถ้าไม่มีสิทธิ์ |

## 10. ข้อควรระวัง

- อย่าใช้บัญชีของคนอื่นขายสินค้า เพราะรายงานจะระบุผู้ขายผิด
- อย่าปิดหน้าเว็บระหว่างกดชำระเงิน
- อย่าล้างบิลถ้าลูกค้าจ่ายเงินและระบบออกใบเสร็จแล้ว
- ถ้าระบบช้า ให้หยุดกดซ้ำหลายครั้งและแจ้งแอดมิน
- ตรวจเงินสดจริงให้ตรงกับยอดขายเมื่อจบกะ
