# คู่มือพนักงานหน้าร้าน

คู่มือนี้สำหรับแคชเชียร์และพนักงานขายของร้านหม่าล่าแดนซ์ by ขวัญใจ ใช้สำหรับขายสินค้า รับเงิน เพิ่มลูกค้าหน้าร้าน และพิมพ์ใบเสร็จ

## 1. เข้าสู่ระบบ

1. เปิด `http://127.0.0.1:8000/login`
2. ใส่อีเมลและรหัสผ่านที่ผู้ดูแลระบบให้
3. กด `เข้าสู่ระบบ`
4. เข้าเมนู `ขายหน้าร้าน`

บัญชีเดโมสำหรับฝึก:

- อีเมล: `demo@qtecsolution.net`
- รหัสผ่าน: `87654321`

## 2. ขายหน้าร้าน

1. เลือกลูกค้า หากเป็นลูกค้าทั่วไปให้ใช้ `ลูกค้าหน้าร้าน`
2. ค้นหาสินค้าด้วยชื่อหรือ SKU
3. กดสินค้าที่ต้องการเพื่อเพิ่มเข้าตะกร้า
4. ปรับจำนวนในตะกร้าให้ตรงกับออเดอร์
5. ตรวจยอดก่อนส่วนลด ส่วนลด ยอดสุทธิ และยอดรับเงิน
6. ใส่ยอดเงินที่ลูกค้าชำระ
7. กด `ชำระเงิน`
8. ยืนยันรายการและพิมพ์ใบเสร็จ

## 3. ตัวอย่างการขาย

ลูกค้าสั่ง:

- หมูสามชั้นหม่าล่า 5 ไม้
- ไส้กรอกชีส 2 ไม้
- ชามะนาว 1 แก้ว

วิธีทำ:

1. เลือก `ลูกค้าหน้าร้าน`
2. ค้นหา `หมูสามชั้น` แล้วเพิ่ม 5 ไม้
3. ค้นหา `ไส้กรอกชีส` แล้วเพิ่ม 2 ไม้
4. ค้นหา `ชามะนาว` แล้วเพิ่ม 1 แก้ว
5. ตรวจยอดรวม
6. รับเงินและกด `ชำระเงิน`
7. พิมพ์ใบเสร็จ

## 4. การใช้ส่วนลด

ใส่ส่วนลดเป็นจำนวนเงินบาท เช่น ลด 10 บาท ให้ใส่ `10` ในช่องส่วนลด ก่อนกดชำระเงิน

ใช้ส่วนลดเมื่อเจ้าของร้านหรือผู้จัดการอนุญาตเท่านั้น และควรตรวจยอดสุทธิทุกครั้งหลังใส่ส่วนลด

## 5. เพิ่มลูกค้าระหว่างขาย

ใช้เมื่อลูกค้าประจำต้องการให้ร้านเก็บประวัติหรือยอดค้างชำระ

1. เปิดช่องเลือกลูกค้า
2. พิมพ์ชื่อลูกค้าใหม่
3. กดเพิ่มลูกค้า
4. เลือกลูกค้าที่เพิ่มใหม่ก่อนชำระเงิน

## 6. การแก้ปัญหาหน้างาน

| ปัญหา | วิธีแก้ |
|---|---|
| หาสินค้าไม่เจอ | ลองค้นด้วยคำสั้น เช่น `หมู`, `ชา`, `น้ำ` |
| สินค้ากดขายไม่ได้ | แจ้งผู้ดูแลระบบให้ตรวจสต็อกหรือสถานะสินค้า |
| จำนวนผิด | ปรับจำนวนในตะกร้าก่อนชำระเงิน |
| ยอดเงินผิด | ตรวจส่วนลดและยอดรับเงินก่อนกดชำระ |
| พิมพ์ใบเสร็จไม่ออก | จดเลขที่บิลไว้ แล้วแจ้งผู้ดูแลระบบตรวจเครื่องพิมพ์ |
| ทำบิลผิดหลังชำระแล้ว | แจ้งผู้ดูแลระบบ ห้ามแก้ข้อมูลเองหากไม่มีสิทธิ์ |

## 7. ข้อควรระวัง

- ใช้บัญชีของตัวเองเท่านั้น
- ตรวจรายการก่อนกดชำระเงินทุกครั้ง
- ห้ามล้างตะกร้าหลังรับเงินจากลูกค้าแล้ว
- หากระบบช้า ให้หยุดกดซ้ำและแจ้งผู้ดูแลระบบ
- ปิดกะแล้วควรแจ้งยอดเงินสดหรือยอดโอนจริงให้ผู้จัดการตรวจ
