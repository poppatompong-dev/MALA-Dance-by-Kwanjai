# คู่มือแอดมิน QPOS ร้านหม่าล่า

## หน้าที่ของแอดมิน

แอดมินคือเจ้าของร้าน ผู้จัดการ หรือผู้ดูแลระบบที่รับผิดชอบข้อมูลหลังบ้านและความถูกต้องของยอดขาย งานหลักมีดังนี้:

- ตั้งค่าร้านและข้อมูลใบเสร็จ
- เพิ่มหมวดสินค้า หน่วยนับ และสินค้า
- กำหนดราคาขายและสต็อก
- บันทึกการซื้อสินค้าเข้าร้าน
- จัดการลูกค้าและผู้จำหน่าย
- จัดการผู้ใช้ บทบาท และสิทธิ์
- ตรวจรายงานยอดขายและสต็อก
- เตรียมระบบก่อนขยายสาขาหรือขึ้น cloud

## 1. ตั้งค่าร้าน

ไปที่ `ตั้งค่า > ตั้งค่าทั่วไป` แล้วตรวจข้อมูลเหล่านี้:

1. ชื่อร้าน เช่น `QPOS ร้านหม่าล่า`
2. ที่อยู่ร้าน
3. เบอร์โทร
4. อีเมลหรือช่องทางติดต่อ
5. โลโก้ร้านถ้ามี
6. ข้อความท้ายใบเสร็จ เช่น `ขอบคุณที่อุดหนุน`

ข้อมูลส่วนนี้ควรถูกต้องก่อนเริ่มขาย เพราะจะไปแสดงบนใบเสร็จและรายงาน

## 2. หมวดสินค้า

หมวดสินค้าช่วยให้พนักงานค้นหาและจัดการเมนูได้ง่าย แนะนำให้แยกตามลักษณะการขาย ไม่ควรใส่ทุกอย่างรวมกัน

หมวดสินค้าแนะนำสำหรับร้านหม่าล่าและเครื่องดื่ม:

- หม่าล่าเสียบไม้
- ชุดหม่าล่า
- เครื่องดื่มเย็น
- เครื่องดื่มปั่น
- ท็อปปิ้ง
- ซอส/น้ำจิ้ม
- ของทานเล่น

การเพิ่มหมวด:

1. ไปที่ `หมวดสินค้า`
2. กด `เพิ่ม`
3. ใส่ชื่อหมวด เช่น `เครื่องดื่มเย็น`
4. เปิดสถานะใช้งาน
5. บันทึก

ถ้ามีเมนูใหม่ในอนาคต เช่น ของหวานหรือข้าวกล่อง ให้เพิ่มหมวดใหม่ได้โดยไม่ต้องเปลี่ยนระบบ

## 3. หน่วยนับ

หน่วยนับใช้กับสินค้าและสต็อก ควรตั้งให้ตรงกับวิธีขายจริง

หน่วยนับแนะนำ:

- `ไม้` สำหรับหม่าล่าเสียบไม้
- `แก้ว` สำหรับเครื่องดื่มชง
- `ขวด` สำหรับน้ำขวด
- `ชุด` สำหรับเซ็ตเมนู
- `ถุง` สำหรับวัตถุดิบหรือซอส
- `กรัม` สำหรับวัตถุดิบที่ชั่งน้ำหนัก

การเพิ่มหน่วย:

1. ไปที่ `หน่วยนับ`
2. กด `เพิ่ม`
3. ใส่ชื่อหน่วยและชื่อย่อ เช่น `ไม้`
4. บันทึก

## 4. สินค้าและราคาขาย

สินค้าเป็นข้อมูลที่แคชเชียร์ใช้ขายหน้าร้าน ควรตั้งชื่อให้ค้นหาง่ายและไม่ซ้ำกันมากเกินไป

ตัวอย่างชื่อที่ดี:

- `หมูสามชั้นหม่าล่า`
- `ไส้กรอกชีส`
- `เต้าหู้ปลา`
- `ชามะนาว`
- `น้ำเปล่าขวด`

การเพิ่มสินค้า:

1. ไปที่ `สินค้า > เพิ่มสินค้า`
2. ใส่ชื่อสินค้า
3. เลือกหมวดสินค้า
4. เลือกหน่วยนับ
5. ใส่ราคาขาย
6. ใส่จำนวนสต็อกเริ่มต้น
7. ใส่บาร์โค้ดถ้ามี
8. ใส่รายละเอียด เช่น ระดับความเผ็ดหรือส่วนประกอบ
9. เปิดสถานะใช้งาน
10. บันทึก

คำแนะนำ: ถ้าสินค้ามีหลายระดับ เช่น เผ็ดน้อย เผ็ดกลาง เผ็ดมาก ให้เลือกวิธีตั้งชื่อให้ทีมขายเข้าใจตรงกัน เช่น `หมูสามชั้นเผ็ดน้อย` และ `หมูสามชั้นเผ็ดมาก`

## 5. สต็อกและการซื้อสินค้าเข้าร้าน

ใช้เมนูซื้อสินค้าเมื่อรับวัตถุดิบหรือสินค้ามาเติมสต็อก เช่น เนื้อหมู ลูกชิ้น น้ำขวด หรือแก้วพลาสติก

ขั้นตอนทั่วไป:

1. ไปที่ `ซื้อสินค้า`
2. เลือกผู้จำหน่าย
3. เลือกสินค้าที่ซื้อเข้า
4. ใส่จำนวนและต้นทุน
5. ตรวจยอดรวม
6. บันทึก
7. ตรวจรายงานสต็อกว่ายอดเพิ่มแล้ว

ควรบันทึกการซื้อทันทีหลังรับของ เพื่อให้แคชเชียร์เห็นสต็อกที่ถูกต้อง ถ้าร้านขายสินค้าที่เตรียมสดทุกวัน ให้แอดมินกำหนดวิธีนับให้ชัด เช่น นับเป็นไม้หรือชุด ไม่ปะปนกับน้ำหนักวัตถุดิบดิบ

## 6. ลูกค้าและผู้จำหน่าย

ลูกค้า:

- ใช้ `ลูกค้าหน้าร้าน` สำหรับลูกค้าทั่วไป
- เพิ่มชื่อลูกค้าประจำเมื่อร้านต้องการดูประวัติหรือยอดค้างชำระ
- ใส่เบอร์โทรเพื่อค้นหาง่าย

ผู้จำหน่าย:

- เพิ่มร้านวัตถุดิบ เช่น `ร้านวัตถุดิบหม่าล่า`
- ใส่เบอร์โทรและที่อยู่
- ใช้ตอนบันทึกซื้อสินค้าเข้าร้าน

ข้อมูลลูกค้าและผู้จำหน่ายควรสะกดให้สม่ำเสมอ เพื่อไม่ให้มีชื่อซ้ำหลายรายการ

## 7. ผู้ใช้ บทบาท และสิทธิ์

แนะนำให้แยกบัญชีผู้ใช้ตามคนจริง เพื่อดูได้ว่าใครเป็นผู้ขายหรือแก้ข้อมูล

| บทบาท | ใช้ทำอะไร | สิทธิ์หลัก |
|---|---|---|
| Admin | เจ้าของร้าน/ผู้จัดการ | ทุกเมนู ตั้งค่า รายงาน ผู้ใช้ และสินค้า |
| Cashier | แคชเชียร์ | ขายหน้าร้าน ดูสินค้า ดูลูกค้า เพิ่มลูกค้า |
| Sales Associate | พนักงานขาย | ขายหน้าร้าน ดูรายการขาย ดูสินค้าและลูกค้า |

แนวทางตั้งค่าสิทธิ์:

1. ให้แคชเชียร์เห็นเฉพาะงานขายประจำวัน
2. ไม่ให้พนักงานทั่วไปลบสินค้า แก้ราคา หรือเข้าหน้าตั้งค่า
3. ให้สิทธิ์รายงานเฉพาะเจ้าของร้านหรือผู้จัดการ
4. ปิดบัญชีทันทีเมื่อพนักงานลาออก

## 8. รายงาน

รายงานที่ควรตรวจเป็นประจำ:

- รายงานขายรายวัน: ตรวจยอดขายตามวันและกะ
- รายการขาย: ค้นหาเลขที่บิลและดูใบเสร็จย้อนหลัง
- รายงานสต็อก: ดูสินค้าคงเหลือและสินค้าใกล้หมด
- รายงานซื้อสินค้า: ตรวจต้นทุนและการเติมของ

วิธีตรวจยอดขายประจำวัน:

1. ไปที่ `รายงานขาย`
2. เลือกวันที่ต้องการ
3. ตรวจยอดรวม ส่วนลด และยอดรับเงิน
4. เทียบกับเงินสด/โอนจริงหน้าร้าน
5. ถ้าตัวเลขไม่ตรง ให้ตรวจรายการขายและเลขที่บิล

## 9. การขยายหมวดสินค้าและสาขา

ระบบสามารถขยายจากร้านหม่าล่าเป็นหมวดอื่นได้ เช่น:

- เครื่องดื่มพรีเมียม
- ของทอด
- เซ็ตอาหารกลางวัน
- สินค้าพร้อมทาน
- ของหวาน

ก่อนเพิ่มหมวดใหม่ ให้กำหนดชื่อหมวด หน่วยนับ และวิธีนับสต็อกให้ชัด เพื่อไม่ให้รายงานสับสน

สำหรับการขยายหลายสาขา ควรวางแผนเพิ่มเติม:

1. ตั้งชื่อสาขาให้ชัด เช่น `สาขาตลาดหน้าโรงเรียน`
2. แยกผู้ใช้ของแต่ละสาขา
3. แยกสต็อกหรือคลังสินค้า
4. กำหนดคนดูรายงานรวม
5. ทดสอบสิทธิ์ก่อนใช้งานจริง

ถ้าระบบเวอร์ชันปัจจุบันยังไม่ได้เปิดหลายสาขาเต็มรูปแบบ ให้ใช้ local สำหรับสาขาเดียวก่อน แล้วค่อยวางแผน cloud หรือฐานข้อมูลกลาง

## 10. Local กับ Cloud

Local:

- เหมาะสำหรับทดลอง ฝึกพนักงาน และใช้ในร้านเดียว
- ใช้ URL `http://127.0.0.1:8000/login`
- ข้อมูลอยู่ในเครื่องที่ติดตั้งระบบ
- ถ้าเครื่องเสียหรือไฟล์หาย อาจกระทบข้อมูล จึงควรสำรองฐานข้อมูล

Cloud:

- เหมาะเมื่ออยากเข้าระบบจากหลายเครื่องหรือหลายสาขา
- ควรใช้ MySQL หรือ MariaDB แทน SQLite
- ต้องตั้งค่า domain จริง เช่น `https://pos.example.com`
- ต้องเปิด HTTPS
- ต้องมีระบบ backup database
- ต้องทดสอบ login, POS, ใบเสร็จ, รายงาน และสิทธิ์ก่อนใช้งานจริง

## 11. Checklist ก่อนเปิดขายจริง

1. ชื่อร้านและข้อมูลใบเสร็จถูกต้อง
2. หมวดสินค้าและหน่วยนับครบ
3. สินค้าหลักมีราคาและสต็อกถูกต้อง
4. มีลูกค้า `ลูกค้าหน้าร้าน`
5. มีบัญชีแคชเชียร์แยกจากแอดมิน
6. แคชเชียร์ทดลองขายและพิมพ์ใบเสร็จได้
7. รายงานขายแสดงข้อมูลถูกต้อง
8. สิทธิ์แคชเชียร์ไม่เห็นหน้าตั้งค่าที่ไม่จำเป็น
9. มีวิธีสำรองข้อมูล
10. เจ้าของร้านรู้วิธีตรวจยอดขายเมื่อจบวัน
