# บันทึกตรวจฟีเจอร์

## สถานะล่าสุด

ระบบถูกปรับเป็น Thai Full Version สำหรับร้าน `หม่าล่าแดนซ์ by ขวัญใจ` แล้วในส่วนข้อมูลเดโม ภาพ placeholder เมนูหลัก POS สินค้า ลูกค้า ซัพพลายเออร์ ใบเสร็จ และตั้งค่าร้าน

## ฟีเจอร์ที่พร้อมใช้งาน

- Login ด้วยบัญชีเดโม
- POS ขายหน้าร้าน
- สินค้าเดโม 12 รายการพร้อมรูป
- หมวดสินค้าและแบรนด์พร้อมรูป
- ลูกค้าและซัพพลายเออร์เดโม
- ซื้อเข้าและเพิ่มสต็อก
- รายงานขายและรายงานสต็อก
- ใบเสร็จและใบแจ้งหนี้ภาษาไทย
- ตั้งค่าร้าน โลโก้ favicon และข้อความท้ายใบเสร็จ

## จุดที่ต้องตรวจด้วยสายตาหลัง build

1. Login page แสดงภาพและโลโก้ถูกต้อง
2. Sidebar และ navbar เป็นภาษาไทย
3. POS แสดงรูปสินค้าเดโมครบ
4. รายการสินค้า หมวดสินค้า และแบรนด์ไม่ fallback เป็น no-image เมื่อมีรูป
5. ใบเสร็จแสดงชื่อร้าน โลโก้ เบอร์โทร และข้อความท้ายใบเสร็จ
6. Settings preview แสดงโลโก้และ favicon ใหม่

## ขอบเขตที่ยังควรปรับต่อหากต้องการ Thai 100%

- หน้าผู้ใช้งาน
- หน้าบทบาทและสิทธิ์
- หน้าสกุลเงิน
- หน้ารายงานย่อยบางส่วน
- ข้อความ validation จาก Laravel request บางรายการ

ส่วนเหล่านี้ไม่กระทบงานขายหลัก แต่ควรเก็บต่อในรอบ polish
