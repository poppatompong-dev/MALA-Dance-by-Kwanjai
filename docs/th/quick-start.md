# คู่มือเริ่มใช้งานเร็ว

## 1. เตรียมระบบ (Local)

```powershell
.\.tools\php\php.exe artisan migrate:fresh --seed --force
npm.cmd run dev
.\.tools\php\php.exe artisan serve --host=127.0.0.1 --port=8000
```

เปิดระบบที่:

```text
http://127.0.0.1:8000/login
```

## 2. เข้าสู่ระบบเดโม

- อีเมล: `demo@qtecsolution.net`
- รหัสผ่าน: `87654321`

## 3. ทดลองขาย 1 บิล

1. เข้าเมนู `ขายหน้าร้าน`
2. เลือก `ลูกค้าหน้าร้าน` (หรือลูกค้าประจำหากต้องการสะสมแต้ม)
3. เลือกประเภทออเดอร์ (`ทานที่ร้าน`, `กลับบ้าน`, `เดลิเวอรี`)
4. ค้นหา `หมูสามชั้น` แล้วเพิ่มสินค้า
5. ค้นหา `ชามะนาว` แล้วเพิ่มสินค้า
6. ถ้ามีสิทธิรางวัล/ส่วนลดให้เลือกใช้ได้
7. ใส่ยอดรับเงิน
8. กด `ชำระเงิน`
9. ตรวจใบเสร็จ POS

## 4. ทดลองสะสมแต้มและใช้แต้ม

1. เปิดเมนู `จัดการสะสมแต้ม/รางวัล` (สำหรับ Owner/Admin)
2. กด `เพิ่มกฎของรางวัล`
3. ตัวอย่างกฎที่ใช้บ่อย:
   - **Earn Points**: ทุกการซื้อ 10 บาท ได้ 1 แต้ม (ค่าเริ่มต้นของระบบ)
   - **Redeem Points**: ใช้ 100 แต้มแลกส่วนลด 50 บาท
   - **Birthday**: ส่วนลด 10% สำหรับลูกค้าวันเกิด
4. กลับมาที่ POS เลือกลูกค้าที่มีแต้ม ระบบจะแสดงรางวัลที่เลือกได้

## 5. ทดลอง Void (ยกเลิกบิล)

1. เข้าเมนู `การขาย > รายการขาย`
2. กดปุ่ม `ยกเลิก (Void)` ที่บิลที่ต้องการ
3. ระบบจะคืนสต็อกอัตโนมัติ คืนแต้มที่ลูกค้าได้รับ และบันทึก audit log

## 6. ตรวจข้อมูลเดโม

เมนูที่ควรเปิดตรวจ:

- `สินค้า > รายการสินค้า`
- `สินค้า > หมวดสินค้า`
- `สินค้า > แบรนด์/แหล่งสินค้า`
- `สินค้า > หน่วยนับ`
- `ลูกค้าและซัพพลายเออร์ > ลูกค้า`
- `ลูกค้าและซัพพลายเออร์ > ซัพพลายเออร์`
- `จัดการสะสมแต้ม/รางวัล`
- `รายงาน > รายงานสต็อก`

## 7. คำสั่งตรวจหลังแก้ไข

```powershell
.\.tools\php\php.exe artisan migrate:fresh --seed --force
npm.cmd run build
.\.tools\php\php.exe artisan view:cache
```

## อ่านคู่มือบนเว็บ

หลัง login เข้าหลังร้านแล้ว สามารถเปิดเมนู `คู่มือการใช้งาน` หรือเข้า URL นี้โดยตรง:

```text
http://127.0.0.1:8000/admin/manuals
```

หน้าเว็บนี้รวมคู่มือเริ่มใช้งานเร็ว คู่มือเจ้าของร้าน คู่มือผู้ดูแลระบบ คู่มือพนักงาน และเอกสารระบบ โดยอ่านจากไฟล์ Markdown ใน repo แบบ read-only

## ทดลองนำเข้าสินค้า

1. เข้าเมนู `สินค้า > นำเข้าสินค้า`
2. กด `ดาวน์โหลดเทมเพลต`
3. เปิดไฟล์ `mala-products-template.xlsx`
4. แก้ไขหรือเพิ่มสินค้าในไฟล์ตามต้องการ
5. เลือกไฟล์แล้วกด `นำเข้าสินค้า`
6. ตรวจผลลัพธ์ที่ `สินค้า > รายการสินค้า`

ระบบจะสร้างหมวดสินค้า แบรนด์ และหน่วยนับใหม่ให้อัตโนมัติถ้ายังไม่มี และจะอัปเดตสินค้าเดิมเมื่อพบ SKU ซ้ำ
