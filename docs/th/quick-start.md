# คู่มือเริ่มใช้งานเร็ว

## 1. เข้าสู่ระบบ

เปิดเว็บ:

```text
https://mala-dance-by-kwanjai.vercel.app/login
```

บัญชีที่ใช้งานได้:

- **ผู้ดูแลระบบ**: `admin` / `admin`
- **เจ้าของร้าน**: `kwan` / `kwan`

(ระบบรองรับการล็อกอินด้วยชื่อผู้ใช้หรืออีเมล)

## 2. ทดลองขาย 1 บิล

1. เข้าเมนู `ขายหน้าร้าน`
2. เลือกประเภทออเดอร์ (`ทานที่ร้าน`, `กลับบ้าน`, `เดลิเวอรี`)
3. เลือก `ลูกค้าหน้าร้าน` (หรือเพิ่มลูกค้าใหม่)
4. ค้นหาสินค้า เช่น `หมูสามชั้น` แล้วเลือกระดับความเผ็ดและเพิ่มเข้าตะกร้า
5. ปรับจำนวนในตะกร้า
6. ใส่ส่วนลด (ถ้ามี) และยอดรับเงิน
7. กด `ชำระเงิน`
8. ตรวจใบเสร็จ POS

## 3. ทดลอง Void (ยกเลิกบิล)

1. เข้าเมนู `การขาย > รายการขาย`
2. กดปุ่ม `ยกเลิก (Void)` ที่บิลที่ต้องการ
3. ระบบจะคืนสต็อกอัตโนมัติและบันทึก audit log

## 4. ตรวจข้อมูลในระบบ

เมนูที่ควรเปิดตรวจหลังเริ่มใช้งาน:

- `สินค้า > รายการสินค้า`
- `สินค้า > หมวดสินค้า`
- `สินค้า > แบรนด์/แหล่งสินค้า`
- `สินค้า > หน่วยนับ`
- `ลูกค้าและซัพพลายเออร์ > ลูกค้า`
- `ลูกค้าและซัพพลายเออร์ > ซัพพลายเออร์`
- `รายงาน > รายงานสต็อก`

## 5. นำเข้าสินค้า

1. เข้าเมนู `สินค้า > นำเข้าสินค้า`
2. กด `ดาวน์โหลดเทมเพลต`
3. กรอกสินค้าในไฟล์ Excel
4. อัปโหลดไฟล์กลับเข้าระบบ
5. ตรวจผลลัพธ์ที่ `สินค้า > รายการสินค้า`

ระบบจะสร้างหมวดสินค้า แบรนด์ และหน่วยนับใหม่ให้อัตโนมัติถ้ายังไม่มี และจะอัปเดตสินค้าเดิมเมื่อพบ SKU ซ้ำ

## 6. อ่านคู่มือเพิ่มเติม

หลัง login เข้าเมนู `คู่มือการใช้งาน` เพื่ออ่านคู่มือทั้งหมด:

- คู่มือเริ่มใช้งานเร็ว (หน้านี้)
- คู่มือเจ้าของร้าน
- คู่มือผู้ดูแลระบบ (รวมแนวทางแก้ไข performance)
- คู่มือพนักงาน
- เอกสารระบบ
