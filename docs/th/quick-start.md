# คู่มือเริ่มใช้งานเร็ว QPOS ร้านหม่าล่า

คู่มือนี้สำหรับเจ้าของร้านหรือพนักงานที่ต้องเปิดระบบบนเครื่อง local ทดลองขายหน้าร้าน และเพิ่มสินค้าเบื้องต้น โดยใช้ตัวอย่างร้านหม่าล่าและเครื่องดื่ม

## 1. เปิดระบบบนเครื่อง local

ให้เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์:

```powershell
cd D:\URY
```

รัน Laravel backend:

```powershell
.\.tools\php\php.exe artisan serve --host=127.0.0.1 --port=8000
```

เปิด Terminal อีกหน้าต่างหนึ่ง แล้วรัน Vite สำหรับไฟล์หน้าจอ React/CSS:

```powershell
npm.cmd run dev
```

จากนั้นเปิดเว็บ:

```text
http://127.0.0.1:8000/login
```

ถ้า Vite แสดง URL เช่น `http://localhost:5173` หรือ `http://localhost:5174` ให้เปิด Terminal นั้นค้างไว้ ไม่ต้องนำ URL ของ Vite ไปใช้งานแทนหน้า login เพราะหน้าหลักของระบบยังอยู่ที่ Laravel URL

## 2. บัญชีทดลอง

ใช้บัญชีนี้เพื่อทดลองระบบ:

- อีเมล: `demo@qtecsolution.net`
- รหัสผ่าน: `87654321`

หลังเข้าสู่ระบบแล้ว ถ้าเห็นเมนูด้านซ้ายและหน้าแดชบอร์ด แปลว่าระบบพร้อมทดลองใช้งาน

## 3. Checklist ก่อนเริ่มขายจริง

ตรวจสิ่งเหล่านี้ก่อนเปิดร้าน:

1. เปิด backend และ Vite แล้ว
2. เข้า `http://127.0.0.1:8000/login` ได้
3. เข้าสู่ระบบด้วยบัญชีทดลองหรือบัญชีแอดมินได้
4. ตั้งชื่อร้าน ที่อยู่ เบอร์โทร และข้อความท้ายใบเสร็จแล้ว
5. มีหมวดสินค้า เช่น `หม่าล่าเสียบไม้`, `เครื่องดื่มเย็น`, `ของทานเล่น`
6. มีหน่วยนับ เช่น `ไม้`, `แก้ว`, `ขวด`, `ชุด`
7. มีสินค้าและราคาขายอย่างน้อย 3-5 รายการ
8. มีลูกค้า `ลูกค้าหน้าร้าน` สำหรับลูกค้าทั่วไป
9. ทดสอบขาย 1 บิลและเปิดใบเสร็จได้
10. ตรวจว่ายอดรับเงิน ยอดค้างชำระ หรือเงินทอนถูกต้อง

## 4. ลำดับทดลองขายหน้าร้าน

ใช้ขั้นตอนนี้เพื่อทดลองขายบิลแรก:

1. เข้าสู่ระบบ
2. ไปที่เมนู `ขายหน้าร้าน` หรือ URL `http://127.0.0.1:8000/admin/cart`
3. เลือกลูกค้า `ลูกค้าหน้าร้าน`
4. ค้นหาสินค้า เช่น `หมูสามชั้นหม่าล่า`, `ไส้กรอกชีส`, หรือ `ชามะนาว`
5. กดสินค้าเพื่อเพิ่มเข้าบิล
6. ตรวจจำนวนสินค้าในบิลด้านขวา
7. ใส่ส่วนลดถ้ามี เช่น ลด 10 บาทสำหรับโปรโมชันหน้าร้าน
8. ใส่ยอดรับเงินในช่อง `รับเงิน`
9. ตรวจ `ยอดสุทธิ` และ `เงินทอน/ค้างชำระ`
10. กด `ชำระเงิน`
11. ยืนยันรายการ
12. ตรวจใบเสร็จ และกดพิมพ์ถ้าต่อเครื่องพิมพ์แล้ว

ตัวอย่างทดลอง: ลูกค้าซื้อหมูสามชั้นหม่าล่า 3 ไม้ ไส้กรอกชีส 2 ไม้ และชามะนาว 1 แก้ว ให้เพิ่มสินค้าทั้งหมดเข้าบิลก่อนรับเงิน เพื่อให้ยอดรวมถูกต้อง

## 5. เมื่อต้องเพิ่มสินค้าใหม่

ตัวอย่าง: เพิ่มสินค้า `เต้าหู้ปลาเผ็ดน้อย`

1. ไปที่ `สินค้า > เพิ่มสินค้า`
2. ใส่ชื่อสินค้า เช่น `เต้าหู้ปลาเผ็ดน้อย`
3. เลือกหมวด เช่น `หม่าล่าเสียบไม้`
4. เลือกหน่วย เช่น `ไม้`
5. ใส่ราคาขาย เช่น `15`
6. ใส่จำนวนสต็อกเริ่มต้น เช่น `50`
7. ใส่รายละเอียดถ้าต้องการ เช่น `ระดับเผ็ดน้อย เหมาะสำหรับเด็ก`
8. บันทึก
9. กลับไปหน้า `ขายหน้าร้าน` แล้วค้นหาชื่อสินค้าเพื่อทดสอบว่าขายได้

ถ้าสินค้าไม่ขึ้นที่หน้า POS ให้ตรวจว่าสินค้านั้นเปิดใช้งาน มีสต็อก และสะกดชื่อถูกต้อง

## 6. ปิดระบบเมื่อเลิกทดลอง

เมื่อเลิกใช้งาน local ให้กลับไปที่ Terminal ทั้งสองหน้าต่าง แล้วกด `Ctrl+C` เพื่อหยุด Laravel backend และ Vite

สำหรับร้านที่ใช้งานจริงทุกวัน ควรให้ผู้ดูแลระบบเป็นคนเปิดเครื่องและเปิดโปรแกรมไว้ก่อนเริ่มขาย เพื่อให้แคชเชียร์เข้าหน้า login แล้วขายได้ทันที
